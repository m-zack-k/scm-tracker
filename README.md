# Smart Supply Chain Tracker

A full-stack Inventory Management System built with **Java Spring Boot** and **Oracle Database**.

This project simulates an Enterprise Resource Planning (ERP) module, featuring automated data integrity checks via **PL/SQL Triggers** and real-time stock tracking.

## 🚀 Tech Stack & Features

* **Backend:** Java 17, Spring Boot 4.0
* **Database:** Oracle Database XE (Express Edition)
* **Frontend:** Thymeleaf, Bootstrap 5
* **Data Integrity:** Custom **PL/SQL Triggers** for audit logging.

## 🏆 Key Highlights (Why this project?)

### 1. Automated Audit Trails (Oracle PL/SQL)
Unlike standard CRUD apps, this system pushes logic to the database layer.
* **Feature:** A database trigger (`log_stock_change`) automatically activates whenever stock levels are modified.
* **Result:** Every transaction is permanently recorded in a separate `inventory_audit` table without requiring extra Java code, ensuring data integrity even if the application layer is bypassed.

### 2. Enterprise Architecture
* Implements **MVC (Model-View-Controller)** architecture.
* Uses **Spring Data JPA** for efficient Object-Relational Mapping (ORM).
* Designed with scalability in mind (Services separated from Controllers).

## 🛠️ How to Run Locally

### Prerequisites
* Java JDK 17+
* Oracle Database XE (or equivalent)
* Maven

### Step 1: Database Setup
Execute the following SQL scripts in Oracle SQL Developer or SQL*Plus to initialize the schema and triggers:

```sql
-- Create Table
CREATE TABLE products (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR2(100),
    sku VARCHAR2(50),
    price NUMBER(10, 2),
    stock_quantity NUMBER
);

-- Create Audit Table
CREATE TABLE inventory_audit (
    audit_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    product_id NUMBER,
    old_stock NUMBER,
    new_stock NUMBER,
    change_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Create The Trigger
CREATE OR REPLACE TRIGGER log_stock_change
AFTER UPDATE OF stock_quantity ON products
FOR EACH ROW
BEGIN
    INSERT INTO inventory_audit (product_id, old_stock, new_stock, change_date)
    VALUES (:OLD.id, :OLD.stock_quantity, :NEW.stock_quantity, SYSDATE);
END;
/
```

### Step 2: Configuration
Update `src/main/resources/application.properties` with your Oracle credentials:

```properties
spring.datasource.url=jdbc:oracle:thin:@localhost:1521:XE
spring.datasource.username=YOUR_USERNAME
spring.datasource.password=YOUR_PASSWORD
```

### Step 3: Run

```bash
mvn spring-boot:run
```
Access the application at: `http://localhost:8080`
